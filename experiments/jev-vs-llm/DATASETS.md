# Public benchmark datasets

The public benchmark tier deliberately uses externally labelled datasets rather than labels generated by Jev or the LLMs under test.

## BANKING77

**Purpose in this repo:** 77-class intent routing and the in-scope half of the calibration benchmark.

Canonical source:

- PolyAI-LDN/task-specific-datasets
- `banking_data/test.csv`
- `banking_data/categories.json`

The public dataset card for `PolyAI/banking77` identifies the dataset as CC BY 4.0. The canonical repository documents 10,003 training examples, 3,080 test examples and 77 intents.

The benchmark uses only the official test split. The code downloads it on demand into:

```text
data/cache/banking77/
```

No BANKING77 rows are committed to this repository.

## CLINC150 / OOS evaluation dataset

**Purpose in this repo:** out-of-scope examples for calibration and rejection behavior.

Canonical source:

- clinc/oos-eval
- `data/data_full.json`
- split: `oos_test`

The upstream repository describes `oos_test` as 1,000 out-of-scope test examples and includes a Creative Commons Attribution 3.0 Unported license.

The benchmark maps every `oos_test` example to the explicit BANKING77 `other` option. This turns the calibration task into:

```text
77 supported banking intents
+ other / out-of-scope
```

The data is downloaded on demand into:

```text
data/cache/clinc150/
```

No CLINC150 rows are committed to this repository.

## Why these two datasets

BANKING77 gives a relatively difficult fixed-choice classification problem with many semantically adjacent intents. CLINC150 contributes independently labelled out-of-scope requests. Together they let the benchmark measure:

- 77-way classification accuracy;
- macro-F1 across many classes;
- probability calibration;
- whether confidence drops on unsupported requests;
- how well an explicit `other` option is used;
- the latency cost of a large fixed decision space.

## Profiles

`compare-public` exposes three cost/coverage profiles.

| Profile | BANKING77 routing | Calibration in-scope | CLINC150 OOS | Intended use |
|---|---:|---:|---:|---|
| `quick` | 154 | 100 | 100 | Integration check / cheap comparison |
| `standard` | 770 | 500 | 500 | Default meaningful experiment |
| `full` | 3,080 | 1,000 | 1,000 | Highest-coverage run |

The BANKING77 routing sampler is class-balanced where a profile uses a subset.

## Download

```bash
uv run jev-bench prepare-data
```

The downloader uses the canonical raw GitHub files and reuses the cached bytes on later runs.

## Reproducibility and attribution

When publishing derived analysis:

1. preserve the upstream dataset attribution and license requirements;
2. record the exact benchmark code commit;
3. record the model IDs, runner location, seed and profile;
4. do not commit or republish upstream dataset bytes unnecessarily;
5. verify separately whether provider terms permit publishing provider benchmark numbers.
